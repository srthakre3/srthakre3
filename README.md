Analytics Engineer / BIE @ Amazon, Seattle, WA

I build data infrastructure that turns raw pipeline data into reliable, self-serve analytics. 5 years at Amazon owning ETL pipelines, dimensional models, and BI solutions across global fulfillment and pharmacy operations.

Currently building a portfolio of open-source analytics engineering projects.

---

## Projects

**[nyc-taxi-elt-pipeline](https://github.com/srthakre3/nyc-taxi-elt-pipeline)**
End-to-end ELT pipeline on 9.5M rows of NYC Yellow Taxi data. Python ingestion into PostgreSQL, dbt transformations (staging, intermediate, dimensional mart), Apache Airflow orchestration, 22 dbt tests passing, and Slack alerts on pipeline completion. Fully containerized with Docker.

**[data-quality-framework](https://github.com/srthakre3/data-quality-framework)**
Production-style Python framework for automated data quality monitoring: schema validation, null/duplicate detection, referential integrity, and statistical outlier alerting. Generates HTML and JSON reports. 6/6 pytest tests passing, CI via GitHub Actions.

**[ecommerce-analytics-platform](https://github.com/srthakre3/ecommerce-analytics-platform)**
Self-serve analytics platform for e-commerce metrics. dbt models (staging, intermediate, marts), KPI layer for GMV, AOV, LTV, and repeat rate. Built for Redshift with a QuickSight dashboard config.
